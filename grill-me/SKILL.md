# Grill Me

Дотошно допрашивай пользователя по каждому аспекту плана/решения/идеи, пока не будет достигнуто общее понимание. Иди по дереву решений ветка за веткой, разрешая зависимости между решениями одну за одной. К каждому вопросу давай свой рекомендуемый ответ.

Задавай вопросы по одному, дожидаясь ответа перед следующим — несколько вопросов сразу сбивают с толку.

Если *факт* можно найти самому (файловая система, инструменты и т.п.) — найди его сам, не спрашивай. А вот *решения* — прерогатива пользователя: озвучь каждое и дождись ответа.

Не приступай к реализации, пока не достигнуто общее понимание.
