Сайд-эффекты: задание

Двенадцать сниппетов со сломанным поведением и один экран, который надо написать целиком. Ответы не приложены намеренно: разбор — со мной, после того как решишь сам.

00 Как решать

На каждый сниппет — три ответа, письменно, своими словами:

  1. Что увидит пользователь. Не «неправильный ключ», а «открыл второй заказ — на экране данные первого». Формулировка через приложение, а не через код, — половина навыка ревью.
  2. Почему так вышло. Через механизм: вход в композицию, ключи как ключи remember, подписка снапшотов, lifecycle.
  3. Как чинить. Готовый код замены.
Правило игры

Сначала без гугла и без статьи — так проверяется, что механизм понят, а не запомнен список рецептов. Не пошло — открывай статью, но помечай, к какому разделу пришлось вернуться: эти разделы и есть твои пробелы.

В сниппетах встречаются и корректные куски — не каждая строка, которая выглядит непривычно, является багом. Один из двенадцати сниппетов рабочий; найти его — часть задания.

01 Двенадцать сниппетов

  1. Детали заказа
    @Composable
fun OrderDetailsScreen(orderId: Long, viewModel: OrderViewModel) {
    LaunchedEffect(Unit) {
        viewModel.loadOrder(orderId)
    }
    val state by viewModel.state.collectAsStateWithLifecycle()
    OrderContent(state = state)
}
  2. Показ экрана в аналитику
    @Composable
fun WalletScreen(viewModel: WalletViewModel) {
    val state by viewModel.state.collectAsStateWithLifecycle()
    analytics.logScreen(screen = "wallet", cardsCount = state.cards.size)
    WalletContent(state = state)
}
  3. Обновление списка компаний
    @Composable
fun CompaniesScreen(viewModel: CompaniesViewModel) {
    val scope = rememberCoroutineScope()
    scope.launch { viewModel.refresh() }

    val state by viewModel.state.collectAsStateWithLifecycle()
    CompaniesList(
        items = state.items,
        onRefresh = { scope.launch { viewModel.refresh() } }
    )
}
  4. Слушатель сканера
    @Composable
fun ScannerScreen(scanner: BarcodeScanner, onCode: (String) -> Unit) {
    LaunchedEffect(scanner) {
        scanner.addListener { code -> onCode(code) }
    }
    CameraPreview()
}
  5. Таймер повторной отправки кода
    @Composable
fun ResendTimer(seconds: Int, onFinished: () -> Unit) {
    var left by remember { mutableIntStateOf(seconds) }

    LaunchedEffect(onFinished) {
        while (left > 0) {
            delay(1_000)
            left--
        }
        onFinished()
    }
    Text(text = "Запросить повторно через $left с")
}

val errorMessage = MutableStateFlow<String?>(null)

// UI
@Composable
fun CheckoutScreen(viewModel: CheckoutViewModel, snackbarHostState: SnackbarHostState) {
    val error by viewModel.errorMessage.collectAsStateWithLifecycle()

    LaunchedEffect(error) {

  7. Баланс в шапке
    @Composable
fun BalanceHeader(viewModel: WalletViewModel) {
    val balance by produceState(initialValue = 0L) {
        viewModel.balanceFlow.collect { value = it }

  8. Подгрузка следующей страницы
    @Composable
fun OperationsList(state: OperationsUiState, onLoadMore: () -> Unit) {
    val listState = rememberLazyListState()

    LaunchedEffect(listState.firstVisibleItemIndex) {
        if (listState.firstVisibleItemIndex > state.items.size - 5) {
            onLoadMore()
        }
    }
    LazyColumn(state = listState) {
        items(state.items, key = { it.id }) { OperationRow(item = it) }
    }
}
  9. Автосохранение черновика
    @Composable
fun ReviewEditor(viewModel: ReviewViewModel) {
    var text by rememberSaveable { mutableStateOf("") }

    LaunchedEffect(Unit) {
        while (true) {
            delay(5_000)
            viewModel.saveDraft(text)
        }
    }
    TextField(value = text, onValueChange = { text = it })
}
  10. Переход после оплаты
    @Composable
fun PaymentScreen(viewModel: PaymentViewModel, navController: NavController) {
    val state by viewModel.state.collectAsStateWithLifecycle()

    LaunchedEffect(state.isPaid) {
        if (state.isPaid) {
            navController.navigate(route = Routes.Success)
        }
    }
    PaymentContent(state = state)
}
  11. Показ баннера в ленте (со звездочкой)
    @Composable
fun FeedList(banners: List<Banner>, onBannerShown: (Long) -> Unit) {
    LazyColumn {
        items(banners, key = { it.id }) { banner ->
            LaunchedEffect(banner.id) { onBannerShown(banner.id) }
            BannerCard(banner = banner)
        }
    }
}
  12. Экран не гаснет, пока идет игра (со звездочкой)
    @Composable
fun GameScreen(isPlaying: Boolean) {
    val window = (LocalContext.current as Activity).window

    DisposableEffect(Unit) {
        if (isPlaying) window.addFlags(FLAG_KEEP_SCREEN_ON)
        onDispose { window.clearFlags(FLAG_KEEP_SCREEN_ON) }
    }
    GameContent()
}

02 Практика: экран подтверждения по коду

Собрать целиком, в study/, отдельным проектом или модулем. Экран знакомый по любому приложению: пришел код в SMS, его надо ввести. Он выбран потому, что в нем сходятся все инструменты статьи разом.

┌──────────────────────────────┐
│  ←                           │
│                              │
│  Введите код из SMS          │
│  Отправили на +7 999 ***     │
│                              │
│   ┌──┐ ┌──┐ ┌──┐ ┌──┐        │  автофокус + клавиатура
│   │ 4│ │ 8│ │  │ │  │        │  при входе на экран
│   └──┘ └──┘ └──┘ └──┘        │
│                              │
│   Запросить повторно  0:47   │  таймер, переживает поворот
│                              │
└──────────────────────────────┘
        ▲ ошибка — снекбар ровно один раз
        ▲ успех  — переход ровно один раз

Требования

  1. При входе на экран поле получает фокус, клавиатура открывается сама.
  2. Отсчет 60 секунд до активной кнопки «Запросить повторно». Поворот экрана отсчет не сбрасывает и не ускоряет.
  3. Как только введены четыре цифры — проверка стартует сама, без кнопки.
  4. Пока идет проверка, ввод заблокирован, на кнопке индикатор.
  5. Неверный код: снекбар с текстом ошибки, поле очищается, фокус возвращается. Снекбар не повторяется при повороте.
  6. Верный код: переход на следующий экран ровно один раз, даже если поворачивать экран в момент перехода.
  7. Экран подписан на состояние сети (или любой другой системный слушатель на выбор) и снимает подписку при уходе.
  8. Composable не хранит бизнес-данные: код, таймер, состояние запроса — во ViewModel. В композиции остается только то, что имеет смысл лишь на живом экране.
  9. Ни одного эффекта без осознанных ключей: на каждый — комментарий из одной строки, почему в скобках именно это.

Чем проверять себя

ПроверкаЧто должно быть
Поворот экрана на 30-й секундеТаймер продолжает с 30, а не с 60
Поворот сразу после ошибкиСнекбар не показывается второй раз
Сворачивание приложения на минутуНикаких запросов в фоне; вернулся — состояние на месте
Быстрый ввод и стирание цифрПроверка не стартует дважды на один код
Счетчик рекомпозиций в Layout InspectorВвод цифры не перерисовывает весь экран
Уход с экрана во время запросаКорутина отменена, коллбэков после ухода нет
Как сдавать

Ответы на сниппеты — текстом, кодом чинить не обязательно, кроме тех, где сам захочешь. Экран — ссылкой на файлы в study/. Разберу по чеклисту из раздела 12 статьи и покажу то, что работает, но развалится на следующем требовании, — это обычно интереснее прямых ошибок.
