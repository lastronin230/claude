# Транскрипция видео по ссылке

Речь ролика доступна только через субтитры. У YouTube они есть почти всегда: либо авторские, либо машинное распознавание. Задача скилла — забрать нужную дорожку, привести к читаемому тексту и отдать так, чтобы результат можно было использовать, а не листать.

**Факты проверены на yt-dlp 2026.08.19.** YouTube меняет правила часто, поэтому при любой непонятной ошибке первым делом смотри `references/troubleshooting.md`, а не подбирай флаги наугад.

## Предусловие: версия

```bash
yt-dlp --version    # 2026.xx.xx или новее
```

Версии 2025.x на YouTube **уже не работают** — падают с `The page needs to be reloaded` или молча не отдают субтитры, требуя PO Token. Ловушка: `pip install yt-dlp` под Python 3.9 ставит именно такую, потому что свежие релизы требуют 3.10. Если версия старая — обнови (`yt-dlp -U`, `brew upgrade yt-dlp`) и только потом разбирайся с остальным.

## Порядок работы

### 1. Разведка — какие дорожки есть

```bash
yt-dlp --list-subs "$URL" 2>&1 | tee /tmp/subs-list.txt
```

Смотри на две таблицы: **Available subtitles** (авторские, с пунктуацией и заглавными) и **Available automatic captions** (машинные). Выбор между ними определяет качество результата, поэтому шаг не пропускается.

Важно: пустая таблица **не означает**, что субтитров нет. Она печатается одинаково и когда их правда нет, и когда они были отброшены из-за ошибки. Ищи `WARNING` выше таблицы — разбор случаев в `references/troubleshooting.md`.

### 2. Забор дорожки

**Есть авторские на нужном языке** — бери их, машинные не нужны:

```bash
mkdir -p /tmp/transcripts && cd /tmp/transcripts
yt-dlp --skip-download --write-subs --sub-langs "ru" \
  --sub-format "json3/srv1/vtt" -o "%(id)s.%(ext)s" "$URL"
```

**Авторских нет** — берем машинную дорожку оригинального языка:

```bash
yt-dlp --skip-download --write-auto-subs --sub-langs ".*-orig" \
  --sub-format "json3/srv1/vtt" --sleep-subtitles 1 -o "%(id)s.%(ext)s" "$URL"
```

`.*-orig` — это язык, на котором ролик реально звучит: YouTube помечает таким суффиксом исходную дорожку распознавания, и знать язык заранее не нужно. Значение `--sub-langs` разбирается как регулярное выражение целиком, а не как подстрока.

**`--sub-format` обязателен.** По умолчанию yt-dlp возьмет `vtt`, а это единственный формат, где YouTube дублирует каждую реплику по два-три раза (эффект ползущих строк на экране) — текст раздувается втрое. В `json3` и `srv1` дублей нет.

**Автопереводы не бери.** Дорожка вида `en-ru` — это машинный перевод машинного распознавания, качество двойной потери, и именно на них YouTube отдает `HTTP 429`. Оригинал (`-orig`) и авторские этой проблемой не затронуты.

### 3. Разбор в текст

```bash
python3 ~/.claude/skills/video-transcript/scripts/transcript.py <файл> -o /tmp/transcripts/<id>.txt
```

Скрипт принимает `.json3`, `.srv1`, `.vtt` и `.srt`, снимает служебную разметку, убирает дубли и режет на абзацы по паузам. Зависимостей нет, только стандартная библиотека.

| Ключ | Что делает |
|---|---|
| (без ключей) | сплошной текст абзацами — для чтения и для пересказа |
| `-m ts -i 60` | блоки с тайм-кодом раз в 60 секунд — когда нужно ссылаться на моменты |
| `--chapters info.json` | вставит заголовки глав ролика (нужен `--write-info-json` при заборе) |
| `-o файл` | записать в файл, в stderr — сводка по количеству слов |

Главы стоит подтянуть, если они у ролика есть: это разбиение, сделанное автором по смыслу, и оно лучше любой эвристики.

### 4. Отдача результата

Транскрипт кладется файлом в `/tmp/transcripts/<id>.txt`, в ответ идут **путь и краткая выжимка** — часовой ролик это 8-9 тысяч слов, вываливать их в чат бессмысленно.

```
/tmp/transcripts/abc123.txt — 27 минут, 4200 слов, машинные субтитры (en-orig)

Доклад про X: первые 10 минут — вводная про Y, дальше разбор трех подходов,
с 18:40 — ответы на вопросы.
```

Дальше работай с файлом по запросу пользователя: пересказ, поиск фрагмента, цитаты, конспект.

## Чего делать не надо

- **Не пересказывай по названию и описанию ролика.** Если субтитры не достались — так и скажи, это честный ответ. Придуманный пересказ выглядит как настоящий и проверяется только просмотром ролика целиком.
- **Не цитируй числа, имена и термины из машинных субтитров как точные.** Распознавание путает «15» и «50», ломает фамилии и жаргон. Если пользователю нужна точная цитата — дай тайм-код, чтобы он сверил со звуком.
- **Не гонись за пунктуацией.** В машинных субтитрах ее нет вовсе: сплошной нижний регистр без точек. Расставить программно нельзя, но пересказу это не мешает.
- **Не предлагай распознавание аудио.** Если субтитров нет — остановись и скажи об этом.

## Если субтитров нет

Останавливайся и сообщай прямо: у ролика нет ни авторских, ни машинных субтитров. Причины бывают разные — автор их отключил, язык не поддерживается распознаванием, ролик слишком свежий и обработка не закончилась.

Перед тем как это утверждать, убедись, что дело не в ошибке: `references/troubleshooting.md` разбирает, как отличить настоящее отсутствие от сбоя.

## Другие площадки

Флаги те же, но форматов `json3`/`srv1` там нет — для не-YouTube цепочка `--sub-format "srt/vtt/best"`.

| Площадка | Субтитры |
|---|---|
| YouTube | да, анонимно, включая машинные |
| Vimeo, TED, Udemy, Dailymotion, Rutube, VK | да; Vimeo требует cookies |
| **Twitch** | **нет** — субтитры не извлекаются в принципе |
| SoundCloud, Instagram | нет |
