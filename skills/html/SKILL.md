# HTML-страница

Скелет — `.claude/templates/page.html`, читать через Read. Копируешь целиком, заменяешь `{{…}}`,
наполняешь `<main>` контентом, подобрав разметку по таблице ниже. Неиспользованные блоки скелета
(оглавление, кнопки копирования, `<pre hidden>`) удаляешь.

## `[STRICT]` Чего в шаблоне нет — то спрашиваем

Не хватает класса, непонятно, чем верстать конкретный кусок, хочется поправить цвет или отступ —
**остановись и спроси пользователя**, предложив вариант. Решение вносится в `templates/page.html`,
и дальше им пользуются все страницы. Дописывать css в самой странице, подгонять цвета на месте или
копировать разметку из старых страниц нельзя: так шаблон разъезжается и правка перестает доставаться
всем.

## Что чем верстать

| Тип информации | Разметка |
|---|---|
| Абзац объяснения | `.prose`, пояснение под заголовком — `.why` |
| Соответствие, было → стало | `<table>` + `td.was` / `td.now` |
| Код, команда | `<pre><code>` |
| ASCII-схема, дерево каталогов | `<pre class="ascii">` |
| Макет экрана, было → стало | `pre.ascii` в `.mock` + `span.gone` / `span.came` |
| Дифф | `.diff` + `.add` / `.del` + `<mark>` на изменившемся фрагменте |
| Ссылка в код | `<a class="src">file:line</a>` |
| Предупреждение, вывод, STRICT | `.note` / `.note.strict` / `.note.ok` с `.tag` |
| Предупреждение внутри абзаца | `<span class="warn">` |
| Список находок, разбор по пунктам | `ol.cards` + `data-s="r|y|g|n"` |
| Сравнение двух подходов, платформ, версий | `dl.xp` |
| Числа, метрики | `td.num` |
| Термин → объяснение | `dl.defs` |
| Инструкция по шагам | `ol.steps` |
| Метки: тема, статус, область | `.chips` + `.chip` |
| Пары ключ-значение в шапке | `.meta` с `.k` / `.v` |
| Поток экранов, слои, граф | inline `<svg>` в `.fig` |
| Список ссылок на другие страницы каталога | `ul.index` — кликабельна вся строка |

Таблица шире экрана — в `<div class="scroll">`. Спецсимволы в `<pre>` и `<code>` экранируются
(`&lt;`, `&amp;`). Тема одна, светлая: блоков `prefers-color-scheme` нет. Все инлайн, внешних
ресурсов нет. Буква «ё» не используется.

В схеме структура рисуется `--muted`, **цвет только на том элементе, о котором речь** — раскрашенная
целиком схема ничего не подсказывает.

## Куда положить

| Просьба | Путь |
|---|---|
| «сделай html» без уточнения, оформление ответа из чата | `tmp/<slug>-<YYYYMMDD-HHMM>.html`, время из `date +%Y%m%d-%H%M` |
| Конспект, документ по теме | `docs/<name>.html`, темы группируются подкаталогом: `docs/<тема>/<name>.html` |

`<slug>` и `<name>` — тема латиницей в kebab-case, 2-4 слова. Каталога нет — создать.

## `[STRICT]` Открывать только новую страницу

- **Создал файл — сразу `open <путь>`**, разрешения не спрашивать. В чат — одна строка с путем,
  содержимое страницы не пересказывать.
- **Поправил существующую — не открывать.** Страница уже открыта у пользователя, ему достаточно
  обновить вкладку (⌘R). Повторный `open` только перекидывает фокус в браузер.

## `[STRICT]` Только то, что уже сказано

Когда страница оформляет готовый ответ или документ — это верстка, а не новая работа. Не досочиняй
разделы, выводы и цифры, которых не было, не ходи в код за дополнительным контекстом, не выбрасывай
оговорки и условия: они часть смысла.
